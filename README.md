# Absürt Gecikme Mazereti Üreticisi

## Dünyanın En Ciddi Gecikme Çözümü (Değil)

Bu repository, insanlığın binlerce yıldır sürdürdüğü "geç kaldım" problemini tamamen çözmek için değil, daha da karmaşık hale getirmek için tasarlanmıştır. 

Her mazeret, bir öncekinden daha absürt, daha inandırıcı olmayan ve daha çok "tamam, neyse" dedirtecek şekilde üretilir.

### Nasıl Çalışır?

```bash
python main.py
```

Program çalıştığında size 5 adet rastgele, bilimsel olarak kanıtlanmamış mazeret sunar. Bunları işvereninize, öğretmeninize veya kediye gönderebilirsiniz.

### Özellikler

- %100 gerçek (değil)
- Zaman bükmesi destekli
- Kahve makinesi terapi modülü
- Gelecekten gelen ben API'si (henüz implement edilmedi)
- Kedi klavye sabotajı entegrasyonu

### Bilimsel Temel

Bu proje, Kuantum Gecikme Teorisi ve Relativistik Mazeret Mekaniği üzerine kurulmuştur. Einstein'in bile "bu kadar saçma olamaz" dediği bir alandır.
